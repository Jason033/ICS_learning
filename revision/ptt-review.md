# PTT 第二版：從基礎機制到維護判讀

使用者指出缺的是基礎內容，不是更多實作。本版重寫原來只有約 800–1100 字的六篇，並審修已存在的兩篇初稿。正文先建立控制與內容、狀態與事件、權利與就緒、時間與內容、結束與未知結果、觀測與推論的關係；C# 只驗證這些規則。

新增兩張與Lab一致的狀態／音訊時序SVG，舊示意圖仍保留但不混用不同模型。八章均有兩份完整推導、操作、同症狀候選鑑別及三層練習；共 65 題，多段答案含計算、條件、證據範圍與回歸。正文連程式約 4520–4912 非空白字元只是防摘要警戒，不當作能力保證。原章節網址不變，舊資源保留。

## 核對資料

2026-10-03 透過 web 讀取官方資料：Zetron Model 6 025-9157M.1 的常規／集群介面（文件 p.13–14 與 p.74），KENWOOD TK-190 QT/DQT／BCL／TOT，ETSI TS124380 V18.6.0（特定 MCPTT 許可機制），Motorola DTR600/700 的特定發話提示、T4512 的特定限時行為；不把產品範例推廣為公司設備。RFC 4582 已被 RFC 8855 取代，本版使用 8855 作仲裁與媒體分工的正式對照，不宣稱公司使用 BFCP。

Microsoft 已核對 lock、Timer.Elapsed 的已排隊回呼、CancellationTokenSource.Cancel、Stopwatch、WPF Dispatcher、事件訂閱與解除、Activity 追蹤、logging/tracing；RTP 時基依 RFC3550。文中計算、Lab 型別與場景均原創，不複製廠商程式或針腳圖。

## 實際驗證與限制

`ptt-maintenance-lab` 為標準函式庫 .NET10 專案，沒有外部套件、SDK、GPIO、RF、聲卡或網路。八模式均在 `/tmp` 副本用 SDK10.0.401 重編執行；實際輸出留 `expected-output.txt`，沒有 bin/obj 留進網站。另做刻意僅以 Ptt 准入的故障變因，應使就緒檢查失敗，再復原跑全模式。

模型以單執行緒、呼叫者給的單調虛擬時間為前提，不模擬自主看門、尾排空、真的樣本內容、硬體或分散式仲裁。Ptt=true 只為本地要求，Ready 是測試注入，不證明設備或對端結果。實際 SDK 版本、針腳、極性、額定、電平、回饋、斷線釋放與恢復需依現有公司系統另核對。

時間由主代理統一按實際內容估算，操作對應斷點、改一項變因與復原；未聲稱已經讀者計時。最後另一位 sockets_finish 代理已全文跨審首章／狀態機／末章，獨立重算陌生數據一致；兩處措辭「區分局部修復」「本地結束」已修。網站全量／發布驗證由主代理另記。
