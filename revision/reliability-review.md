## 已執行的驗證

獨立 `reliability-maintenance-lab` 已複製至暫存目錄，以 .NET SDK 10.0.401 編譯並執行八個模式（all）。全部不變條件檢查通過。輸出保存在專案的 `expected-output.txt`。`race` 用真實 Thread／Barrier 建立可重現的遺失更新；其他模式用固定邏輯時間與資料，沒有連網或設備動作。

作者人工核對時間預算、6秒佇列、序號範圍、百分位與UI等待算式。另外把正文四段預算、完整鎖／快照型別、trace record、封頂退避片段放入獨立Console脈絡實際編譯執行；30／0預算、舊版本不覆蓋新快照、期限不足與大重試索引的溢位邊界均通過。UI／SDK相關片段仍是追讀，不宣稱已在真實框架執行。C#的核心API依 Microsoft Learn 原始文件核對；keepalive 依 RFC1122，監測依 Google SRE，重試與冪等依 AWS 官方說明。各章保存直接來源，並明示政策與模型限制。

## 不能從這些驗證推出什麼

Console不具WPF Dispatcher；async模式是派送的邏輯演算，沒有驗證畫面反應。記憶體中的單執行緒字典不是交易式去重，不能提供真實「恰好一次」。SDK、設備心跳、備援仲裁、部署負載及公司.NET Framework相容性均未實測；需要對應版本與實際程式證據。這些界線在正文有解釋，不能僅留在報告末尾。

時間分成閱讀、操作、作答；閱讀會由統一工具按實際內容重算，全部仍待個人計時校準。字數和題數只能檢查缺漏，最終是否教清楚需跨作者審查與讀者回饋。
